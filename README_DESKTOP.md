# Wenku8 Audio Archive 桌面客户端 (Windows)

立体白盒磁带书架 × 深色极简音乐播放器（集成 Folia 17 种动力学视觉动效 & 网易云音乐在线曲库）

---

### 🚀 启动与使用

1. **直接启动**：
   - 双击根目录下的 **`Wenku8Player.exe`** 或 **`启动播放器.exe`**；
   - 程序将自动在后台静默拉起音频服务端，并以**独立原生软件窗口**（无浏览器地址栏与标签页）的形式打开播放器。

2. **桌面快捷方式**：
   - 安装脚本已自动在您的 Windows 桌面上创建了 **`Wenku8 Audio Archive`** 快捷方式，双击桌面图标即可直接开启。

3. **托盘与后台控制**：
   - 启动后，右下角任务栏托盘会显示磁带专属图标 📼；
   - **双击托盘图标**：唤起播放器主窗口；
   - **右键托盘图标**：可选择「打开播放器窗口」、「在浏览器中打开」或「🚪 退出软件」（将同步自动释放后台 Node.js 服务进程）。

4. **快捷关闭**：
   - 如需一键强制清理所有后台服务，可双击运行 **`关闭播放器.bat`**。

---

### ✨ 功能亮点

1. **17 种 Folia 视觉动效**：播放页顶部常驻 17 种动力学歌词视觉模式，实时提取 Web Audio 频率能量与节拍脉冲。
2. **纯白 3D 磁带书架 (Cover Flow)**：深度支持视口动态剔除、齿轮旋转、物理回弹与多色磁带面板。
3. **网易云音乐原生对接**：支持无感扫码登录、个人歌单无损串流加载、双行滚动歌词同步解析。
